## 1. 业务数据分工（谁产出什么）

```mermaid
flowchart TB
    FILE(["回函文件（上传）"])

    subgraph AI["AI 读取 —— 给结论，人工在核验页逐项采纳 / 人工改写"]
        A1["一致性比对<br/>逐项科目金额 + 差异额"]
        A2["印章识别<br/>是否盖章 · 骑缝章<br/>章名一致 · 落章区域"]
        A3["手写体转录 + 所处区域"]
        A4["银行函证四要素<br/>+ 询证项金额"]
        A5["快递面单<br/>运单号 · 快递公司<br/>发件人 · 寄件时间"]
    end

    subgraph HUMAN["必须人工录入 / 判断 —— 系统无法产出"]
        H1["收件人姓名 / 电话 / 地址"]
        H2["函证结果是否相符（必填）"]
        H3["盖章是否与被询证方名称一致（必填）"]
        H4["是否为公章（必填）<br/>是否有骑缝章（必填）"]
        H5["两句说明：不相符处描述<br/>盖章不一致原因描述"]
        H6["两个附件：替代性测试文件 · 差异调节表<br/>一段文本：进一步核查程序与底稿指引"]
        H7["银行函证归属确认"]
    end

    subgraph SYS["系统自动推导 —— 无需人工维护"]
        S1["归属落点 · 风险等级与原因"]
        S2["回函进度 · 最终有效回函"]
        S3["核验人 + 核验时间<br/>最近修改留痕"]
        S4["核验意见留痕<br/>采纳 / 不采纳 · 处理人 · 时间 · 不采纳原因"]
    end

    FILE --> AI
    AI -->|"逐项采纳，代入人工确认列"| REC
    HUMAN -->|"在人工确认列 / 结果页录入"| REC
    SYS -->|"自动写入"| REC
    REC["回函记录（列表一行 = 一封函证）"]
```

## 2. 数据流转路径

```mermaid
flowchart TB
    U(["业务人员按函证类型上传回函文件<br/>往来函证 / 银行函证（两个并列入口）"]) --> B["批次：函证类型随上传入口确定"]
    B --> SEG["【回函归属】界面（独立全屏）<br/>把文件切成段 · 逐段指定归属<br/>两类函证都不依赖识别进度，打开即可动手"]
    B -.->|"上传后即在后台并行推进<br/>不阻塞归属操作"| P1["第一批识别（归属类）<br/>往来：二维码分段初稿 · 印章 · 手写体 · 面单<br/>银行：四要素识别"]
    SEG --> M{"归属匹配结果"}
    M -->|"往来：二维码精确命中，逐段人工核对"| K["点「确定」= 切分与归属一并提交"]
    M -->|"银行：四要素命中 → 预填归属"| C["在每段的归属下拉里核对或改选"]
    M -->|"银行：未命中 → 下拉留「待指定」"| D["人工从候选函证里指定"]
    K --> F
    C --> F
    D --> F
    F["确定归属 = 唯一的落库入口<br/>归属未确定绝不落库<br/>银行侧先只落四要素，其余标注「识别中」"] --> R["回函记录落库<br/>进度 = 待确认快递信息"]
    F -.->|"银行第二批（询证事项逐项核对 + 印章两项）<br/>判据要用到该函证的被询证单位，故归属确定后开跑"| P2["第二批：银行其余检测项"]
    P2 -.->|"识别完成，回填结论"| R
    R --> V["确认回函快递信息<br/>确认即记录核验人与时间（唯一的核验留痕）"]
    R --> VV["AI 智能核验：三个检测页签逐项表态<br/>采纳（自动代入人工确认列）/ 不采纳（须填原因）<br/>人工确认列写的是一份回函结果草稿"]
    VV -->|"第 4 项「回函结果补充」点「保存」<br/>= 草稿唯一的落库出口<br/>（核查项全表态 + 必填全有值 → 同时归档）"| RS
    V -->|"确认并留痕；回函结果未填"| P["进度 = 待填写回函结果"]
    V -->|"确认并留痕；回函结果已填 → 直接完成<br/>（两步各自独立，先填哪个都可以）"| E
    P --> RS["填写并保存回函结果<br/>必填：是否相符 · 盖章是否与被询证方名称一致<br/>· 是否为公章 · 是否有骑缝章"]
    RS -->|"保存"| E(["进度 = 已完成 · 归档（两步都完成）"])
    X["快递数据（Excel 导入）"] -.->|"按运单号匹配（独立 · 可选）"| R
```

## 3. 回函进度状态机

```mermaid
stateDiagram-v2
    direction TB
    [*] --> S1 : 上传回函文件并匹配到函证
    S1 --> S2 : 确认回函快递信息（同时记录核验人与时间）
    S1 --> S3 : 确认回函快递信息（回函结果已填 → 直接完成）
    S2 --> S3 : 填写回函结果并保存
    S2 --> S3 : 在核验页第 4 项「回函结果补充」点「保存」（核查项全表态 + 必填全有值）
    S3 --> S3 : 修正已填内容（进度仍为已完成，仅记录最近修改人与时间）
    S1 --> S1 : 查看 / 修正已保存内容
    S2 --> S2 : 查看 / 修正已保存内容
    S1 : 待确认快递信息
    S2 : 待填写回函结果
    S3 : 已完成
```

## 4. 业务人员的操作路径

```mermaid
flowchart TB
    START(["一批回函文件"]) --> OP1["① 列表页按函证类型点上传<br/>「上传往来函证回函」<br/>或「上传银行函证回函」拖入文件"]
    OP1 --> OP2["② 在「回函切分与归属」界面切成段<br/>逐段指定归属，点「确定」提交<br/>（提交后回列表；识别已在后台跑）"]
    OP2 --> OP3["③ 在列表页等识别跑完<br/>识别区逐封交代进度，跑完一封＝表格多一行"]
    OP3 --> OP4["④ 点「核查事项复核」格（落在第一个未完成事项）<br/>逐项看依据 → 采纳（自动代入人工确认列）<br/>或不采纳（须填不采纳原因）<br/>表态后自动前进到下一项"]
    OP4 --> OP5["⑤ 最后一个核查项办完，自动落到第 4 项「回函结果补充」<br/>补两个附件与底稿指引，点「保存」<br/>（核查项全表态 + 必填全有值 → 归档）"]
    OP5 --> OP6["⑥ 点进度列步骤条第一步「快递信息」<br/>确认快递信息（确认即记录核验人与时间）"]
    OP6 --> OP7["⑦ 点步骤条第二步「回函结果」<br/>补齐必填项并保存 → 归档"]
    OP7 --> OP8{"还有待办？"}
    OP8 -->|"有"| OP3
    OP8 -->|"没有"| DONE(["本批处理完"])
    LOOK["可选：查看识别过程<br/>查看识别进度与各检测项依据"] -.-> OP3
    OPX["可选：导入快递数据<br/>Excel 补物流详情"] -.-> OP3
    FIX["已填内容需修正<br/>点进度列的对应步骤再打开<br/>修改不改变回函进度<br/>只记最近修改人与时间"] -.-> OP3
```
